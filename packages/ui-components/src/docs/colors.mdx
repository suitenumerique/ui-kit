# Colors

La Suite UI exposes global palettes and semantic color tokens. Prefer semantic
tokens in application code because their values adapt to the active theme.

## Contextual backgrounds

Use `.bg-{semantic-path}` utility classes for backgrounds:

<Source
  language="tsx"
  dark
  format={false}
  code={`<div className="bg-semantic-brand-primary" />`}
/>

## Global palette classes

Global colors are also available as `.bg-{palette-key}` and
`.clr-{palette-key}`, for example `bg-purple-500`. Use them when an exact
palette value is required; semantic tokens should remain the default choice for
product interfaces.

## Customize a color

Colors are configured under `themes.<name>.globals.colors`:

<Source
  language="ts"
  dark
  code={`import type { Configuration } from "@gouvfr-lasuite/ui-components";

const config = {
themes: {
default: {
globals: {
colors: {
"brand-500": "#6a5acd",
"amazing-500": "#ff69b4",
},
},
},
},
} satisfies Configuration;

export default config;`}
/>

With utility-class generation enabled, the additional color creates
`bg-amazing-500` and `clr-amazing-500`. See
[Customization](?path=/docs/getting-started-customization--docs) for the full
generation workflow.
