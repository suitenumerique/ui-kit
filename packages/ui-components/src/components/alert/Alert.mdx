# Alert

A thin wrapper around Cunningham's [`Alert`](https://suitenumerique.github.io/cunningham/storybook/?path=/docs/components-alert--docs)

## Props

### `children`

The message of the alert. Any React node works, but it is usually a short
sentence describing the information, success, warning or error.

<Canvas of={AlertStories.Info} />

### `type`

The visual variant, from Cunningham's `VariantType` enum: `info`, `success`,
`warning`, `error` or `neutral`. Defaults to `info`.

<Canvas of={AlertStories.Success} />
<Canvas of={AlertStories.Warning} />
<Canvas of={AlertStories.Error} />
<Canvas of={AlertStories.Neutral} />

### `canClose`

When `true`, a close button is rendered at the end of the action row, letting
the user dismiss the alert.

### `primaryLabel` and `tertiaryLabel`

Labelled buttons rendered in the action row. They wear a borderless 32px look,
tinted with the alert variant. `primaryOnClick`, `primaryProps`,
`tertiaryOnClick` and `tertiaryProps` let you wire and customise them.

<Canvas of={AlertStories.LabelledButtons} />

### `actions`

Either a ready-made React node, or a list of `{ label, onClick }` descriptors
rendered as borderless buttons matching the variant.

<Canvas of={AlertStories.Actions} />

### `buttons`

A React node appended after the labelled buttons. Unlike `actions` descriptors,
a node keeps whatever look you give it.

<Canvas of={AlertStories.CustomButtons} />

### `icon` and `hideIcon`

`icon` replaces the leading icon, `hideIcon` removes it altogether.

<Canvas of={AlertStories.WithoutIcon} />
