# Support forms

Forms that let users write to a team: a subject, a message, an optional file
and their email. They open in a popover next to the button that triggers
them, and take the full screen on mobile.

Both must live under a `CunninghamProvider`: their labels are translated in
the 5 supported languages, and can be overridden with the `labels` prop.

## GenericSupportForm

```tsx
const [isOpen, setIsOpen] = useState(false);

<GenericSupportForm
  isOpen={isOpen}
  onOpenChange={setIsOpen}
  onSend={(data) => api.sendFeedback(data)}
>
  <Button onClick={() => setIsOpen(true)}>Contact us</Button>
</GenericSupportForm>;
```

- The fields are checked when the user clicks Send: each error is shown and
  the focus moves to the first invalid field.
- When `onSend` returns a promise, the form shows a sending state, then a
  success view when it resolves, or the error message when it rejects.
- `requireEmail` makes the email mandatory, and `email` passes the email of
  the current user so the form does not ask for it.
- `maxFiles`, `maxFileSize` and `acceptedFileTypes` limit the attachments;
  a refused file says why.
